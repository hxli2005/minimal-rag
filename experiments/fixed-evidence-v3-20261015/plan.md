# v3固定证据回答层小样本对照

以已采用v3为基线，只改变最终作答要求。用户已授权先做小样本，观察准确率、事实完整度和成本后再决定是否值得完整评测。本轮不自动启动完整RAG评测，不改变当前采用版本。

主样本沿用2026-10-12冻结的Enterprise dev24，覆盖10种问题类型；额外单列qst_0341、qst_0013两道已曝光事实遗漏诊断题。主24题与诊断2题分别汇报，不将有意选出的错题混入主样本指标。全部为已知开发题，不估计未见数据总体准确率。

每题只使用v3已保存轨迹中search/read实际返回的正文。按原始文档ID合并重叠或相邻区间，保留首次出现的文档顺序，不扩充未见文本、不折叠跨版本别名、不按gold挑片段。精确核对区间与同ID原文。去除重复正文、旧答案和历史模型推理；两组拿到完全相同的题目与正文输入。

两组均重新生成，不复用历史答案。控制组保留v3系统提示；候选组只追加：

> 按问题子项逐条回答。每条结论保留原文中会改变含义的适用范围、前提与例外、数值与时间，并将条件和对应动作写在一起、标注来源。不同版本或状态分别说明；缺少依据的子项明确说明。遵守问题要求的最终输出格式。

两组均使用当前Codex适配器、gpt-6.1-sol/high，每题一个全新会话、一次最终生成，无检索工具。180秒请求超时；失败保留原分母且不重生成。共用固定证据说明及末轮收束提示。它是回答层诊断，不是复现v3完整检索轨迹，也不将新控制组准确率与历史82/100直接相减。

裁判沿用v3的sol/medium、原PROMPT、原参考答案与事实列表；裁判看不到组名、候选提示或另一组答案。只因传输/schema失败最多3次，首个有效评分（包括false）永久保留。正常52生成＋52评分＝104次，硬上限208次，生成并发4、裁判并发1、运行最长60分钟。每次请求前记账；记录生成和评分各自输入、缓存、未缓存输入、输出及缺失用量，不将订阅token换算成虚构金额。

题目顺序与每题两组先后顺序用seed20261015冻结；两种先后各13题。报告主24题准确率、逐题平均事实支持率、按事实计的支持率、正确性×完整度、胜负与配对bootstrap区间，以及生成成本、输出量、答案长度和失败。2道诊断题逐题单列。bootstrap只刻画题目抽样，不覆盖重复生成或裁判波动，不用区间下界机械淘汰。

进入完整评测的方向性信号：主24题准确数不下降且事实完整度提高至少3个百分点，或至少净赢2题且完整度不下降；生成未缓存输入不超过控制组1.10倍。若只出现答案增长、无准确率或事实覆盖收益，则停止扩样。相近或冲突结果结合逐题原文审查，不改参考或翻分；本轮只给出是否值得完整评测的判断，不自动晋级。
