# BGE-small 与 Qwen3-Embedding-0.6B 离线对照

日期：2026 年 10 月 12 日。状态：四组编码与 dev100 离线检索完成；在线生成、裁判调用均为 0。

## 主要观察

Qwen 0.6B 在本候选库中改善了 semantic 检索：片段 recall@20 从 36% 到 76%，句子／行从 36% 到 68%。两种粒度均达到相对 BGE 的预设质量筛选线。

句子化本身没有胜出：Qwen 句子组相对片段组总体低 1.33 个百分点，semantic 低 8 个百分点；semantic 同题为 2 胜、4 负、19 平。BGE 的 semantic recall@20 则在两种粒度下均为 36%。这不能证明句子路线普遍更差，但当前结果不支持把它当成质量升级。

关键词仍有互补价值。Qwen 片段组的总体 recall@20 为 83.24%，与正文 BM25 片段参照的 84.40% 接近；在 semantic 类，Qwen 相比该 BM25 新命中 5 个目标文档、丢失 2 个，两路各取 20 篇的并集为 84%。并集不是等预算融合结果。

## 实验范围

共用 4,646 篇候选文档，含 135 篇目标文档、原全库检索的干扰文档与 1,000 篇固定哈希背景文档。旧片段 22,591 个；句子／原文行 278,980 个。

这是给定候选库中的已知开发集诊断，不是完整 Enterprise 语料检索、答案准确率或官方成绩。总体召回按 94 道有目标文档的题计算；semantic 类 25 道均可计分。另 6 道无目标文档标签的题保留记录，召回记为不适用。

原题直接检索，正文编码，不拼标题，不改写问题，不重排、不用 ANN。每题先取前 100 个单元，再按文档去重取前 k 篇。BM25 是相同文档池上的正文检索参照，使用 unicode61 和 OR 词项；它不等同于旧全库的标题加权、porter 分词配置。

## 粒度退步的检查

semantic 25 题的六个条件都返回了 20 个不同文档，因而不是前 100 个单元不足以凑齐 20 篇文档的问题。对这个固定排序直接增加候选数，也不会改变已经出现的前 20 篇文档。

四道从片段成功变为句子失败的题分别涉及区域切换的配额计算原因、客户 POC 合规条件、流量放量计划和事故首小时的步骤。原文检查显示这些问题需要连接症状与原因、项目背景与条款或多个步骤；单句可能缺少这些关联，但这是基于样例的解释，尚未通过新的对照证明。原始最佳目标单元保存在摘要 JSON 中。

建议下一步保留 0.6B，只做“原句”与“标题＋原句”的受控离线比较，检索返回仍保持原句；暂不全量建库或在线评测。本轮没有执行这项建议。

## 复现与证据

本机已具备原文库、旧 BGE 索引及固定权重时，在仓库根目录使用新输出目录执行；这些是离线命令，不调用生成或裁判模型：

```bash
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false
export VECLIB_MAXIMUM_THREADS=4
RAG_STUDY_OUTPUT=runs/my-offline-reproduction
python -m minimal_rag_experiments.sentence_retrieval prepare --output "$RAG_STUDY_OUTPUT"
for model in bge qwen; do
  python -m minimal_rag_experiments.sentence_retrieval probe --output "$RAG_STUDY_OUTPUT" --model "$model"
  python -m minimal_rag_experiments.sentence_retrieval encode --output "$RAG_STUDY_OUTPUT" --model "$model" --max-seconds 10800
done
python -m minimal_rag_experiments.sentence_retrieval evaluate --output "$RAG_STUDY_OUTPUT"
```

需要安装主包的 `retrieval` 扩展和独立实验包。固定模型是 BGE revision `5c38ec7c405ec4b44b94cc5a9bb96e735b38267a` 与 Qwen 0.6B revision `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`；BGE 使用 `models/hybrid-rag/models-minilm.json`，Qwen 使用 `models/sentence-rag/embedding-qwen3-0.6b.json`。后者保存 `model`、`revision`、本机权重 `path` 与下载完成后才可设为真的 `complete`，不能用不存在的本机路径或不同版本代替。

本轮核心未改动，122 项离线测试通过。编码及计分流水线耗时约 52.8 分钟，不含此前资料池选择和模型下载；没有自动启动下一阶段。
