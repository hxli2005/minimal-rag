# 长度与失败层核对：30题中22题已暴露全部参考原文

**结论：长度不能定位瓶颈；这30道题的现有证据不支持“阅读层略多”的猜测。** 复用了既有exposure_audit的原文切片核对与区间并集逻辑，针对v0/sota-20261014的Enterprise test400重新选择并核对30题。22题全部参考原文已暴露，8题只有部分正文；0切片不匹配、0跨版本别名坐标混用。没有新增模型调用、修改评分或启动实验。

## 本地扣分拆解可以复现

| 项目 | 重新计算结果 |

| 判错带来的综合分损失 | 19.00pp |

这些是v0历史test400，不能写成v3已完成test。19pp是判错结果的计分损失，不是检索层的损失；漏核心事实同样会进入这个桶。30/400=7.5pp只是选中题目的规模，不是可获得的提分预测。零参考事实被支持也不能直接命名为“完全编造”，可能涉及拒答、错实体、标签或参考边界。

## 暴露审计的含义与人工核查

原`exposure_audit.py`只核对文档字符暴露，不自动判断每条自然语言事实是否被支持，更不会自动区分“阅读”与“回答”原因。

- **22题全文已暴露**：按既定参考文档，不能再用“模型只看到摘录、没读到这份参考正文”解释。但仍需区分作答遗漏、条件/版本理解、过度保留意见与参考/裁判问题；不能把22题全部计为纯回答层失败。
- **8题正文部分暴露**：不能自动归为阅读失败，缺失的参考事实可能位于已经看到的区间。
- **不能外推比例**：这30题本来就是从“错、部分事实支持、全部参考ID返回”筛选而来，不代表全部76错题或全部400题的层级占比。

对缺失事实作了定向原文核查，结果进一步说明不能按全文覆盖率直接分类：

| --- | --- |

| qst_0089，正文部分暴露 | recent validator success条件已经出现在返回区间，不能因整篇未读完而归为阅读失败 |
| qst_0378，正文部分暴露 | 14天spend／30天compliance冷却期，以及2+ sessions/48h条件均在已见区间；答案混用或省略 |

| qst_0342，正文部分暴露 | 禁止对外披露精确超时／重试／熔断阈值的特定参考段落不在返回区间；部分其他被漏事实实际上已见。未穷尽所有等价表达，不能宣称该事实在全部观察中绝对不存在 |

这些是人工选出的具体证据核查，不是完成了所有缺失事实的语义审定。原始事实、正文、区间、答案和判决都保留，分数不改。

## 公开榜单长度统计：方向接近，样本快照不同

读取官方公开答案与判决，固定到Hugging Face revision `c4b7d6ed680f16770c498583ebcba1cd63c30470`。该快照有34套完整500题答案/判决，并非引用中的29套。因此不把新结果冒充对“29系统／3,191对”的精确复现。

| 当前快照统计 | 结果 |
| --- | ---: |
| 34系统：答案字符中位数与overall的Spearman相关 | 0.4872 |
| 当前前10名相关 | 0.3939 |
| 前10名同题正确性不一致的配对 | 3,130对，涉及195个不同问题 |
| 上述配对中正确答案更长 | 1,515/3,130＝48.40%，另1对等长 |
| overall≥74的系统数 | 12，不是10 |
| 这12系统同题配对中正确答案更长 | 2,394/4,852＝49.34% |

这些结果支持“长答案不具备稳定的观察优势”，但不能证明长度没有因果作用：同题比较仍更换了模型、检索、实际证据，有些官方题目还按系统提交作了参考修订；同一个问题和系统反复出现，配对不是独立试验。头部相关受小样本和分数范围缩窄影响，也不能用来宣称因果关系不存在。长度按原始answer字段Unicode字符计算，含格式与引用。

## 对优化方向的判断

应继续研究已见证据的完整、准确使用，不能据此要求统一加长答案，也不应未经核查就优先增加search摘录。既有两次实验只检验了两个具体提示，不能证明“所有仅改提示的办法都无效”。固定证据小样本的事实完整度+2.61pp、本地正确性×完整度+3.125pp，以及定向题qst_0341错→对，仍是局部正信号；不能放大为总体提分，也不能忽略。

保持单一主实现收敛的优先级。后续在同一实现上按事实区分未曝光、已曝光但遗漏/误解、参考/判分争议，再选择一项通用改动。当前没有证据把两层量化为一半一半。
