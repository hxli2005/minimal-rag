03 — The interface

The tools arethe product.工具接口，才是产品。

Same model. Same BM25 index. Same 230 queries. Swap our search/read for the benchmark's standard search tool and correct answers drop from 217 to 194. The gain is interface design, not only the model.同一模型、同一 BM25 索引、同样 230 道题。把我们的 search/read 换成基准自带的标准搜索工具，答对数从 217 掉到 194。提升来自工具接口设计，而不只是模型。

04 — Architecture

The whole loopfits on one screen.整个循环，一屏装下。

The model replies with text or tool calls. The loop runs the tools and appends what they return. That is the entire control flow — judgment lives in the model, capability lives in the tools, so a stronger model makes the whole system stronger.模型返回文本或工具调用；循环执行工具、把结果追加回上下文。控制流就这些——判断交给模型，能力交给工具，所以模型变强，整个系统直接变强。

07 — Fine print

  
The fine print,in large print.限制条款，用大字写。

  

    
/01
Not yet official.还不是官方成绩。Both submissions are with the maintainers. BrowseComp was scored by us with the official script; Enterprise official grading is pending.两份提交都在等维护方处理。BrowseComp 由本项目用官方脚本判分；Enterprise 等待官方判分。

    
/02
Development sets, not held-out sets.回归集，不是留出集。Both benchmarks were used during development. Enterprise dev/test is our own split. One generation per question except technical reruns; failures stay in the denominator.两个基准都在开发中用过；Enterprise 的 dev/test 是本项目自己的划分。除技术错误重跑外每题生成一次，失败计入分母。

    
/03
Eight reruns, disclosed.8 道重跑，全部公开。Timeouts, usage limits and SDK interrupts hit eight BrowseComp queries; each was rerun once with the same configuration. Counted as wrong: 93.37%.8 道 BrowseComp 题遇到超时、额度和 SDK 中断，各用相同配置重跑一次。全算错则为 93.37%。

    
/04
Full runs used the Codex SDK.全量成绩来自 Codex SDK。Codex injects extra tool definitions and multi-agent text; traces show no built-in tool calls. The direct API backend was only migration-tested on Enterprise dev30.Codex 会注入额外工具定义和多智能体说明，轨迹中无内置工具调用。直连 API 后端只在 Enterprise dev30 上做过迁移验证。

    
/05
One change to the judge script.判分脚本只改一处。BrowseComp judging ran on one A800 with max_model_len=8192 added. The longest judge prompt is 1,216 tokens, so nothing is truncated.BrowseComp 判分在单张 A800 上运行，仅加入 max_model_len=8192；最长判分提示 1,216 token，不会截断。

    
/06
A student project.个人学生项目。Budget-limited. Every question keeps an inspectable trace, configuration and evaluation record.受预算限制。每道题都保留可检查的轨迹、配置和评测记录。
